# ⚗ AlchemicaSampler — framing presets (shot size, camera angle, subject view)
#
# One preset per [section]. The name in brackets is what the ⚗ Prompt menus show.
#   group      shot | angle | view
#   text       the framing sentence that opens the scene (English works best)
#   aspect     shot only: frame shape used in 'strict' mode (1:1 2:3 3:2 3:4 4:3 4:5 5:4 9:16 16:9 21:9)
#   megapixels shot only: size used in 'strict' mode
#   negative   framing negatives added in 'strict' mode (comma separated); for a view, the opposite views
#   anchor     shot only: sentence added when the scene never mentions legs or feet (default: the whole
#              body is visible from head to toe); a smaller figure for the wide shots
#   hide       shot only: 'legs' or 'feet' = what the frame cuts away; descriptions of it are removed
#              from the scene (a reference photo or the LLM often describe the whole outfit)
#
# To add or change presets WITHOUT editing this file, write the same format in
#   ComfyUI/user/alchemica/shots.txt
# (a section with the same name replaces the one here). Restart ComfyUI or press R to refresh the menus.
# A thumbnail for the gallery is shots/thumbs/<name>.jpg (or user/alchemica/shot_thumbs/<name>.jpg),
# where <name> is the section name with every character that is not a letter or digit turned into '_'.
